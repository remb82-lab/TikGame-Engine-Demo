# Security Policy

## Supported version

Security fixes target the current `main` branch of this public demo.

## Reporting a vulnerability

Do **not** open a public issue containing passwords, API keys, tokens, private endpoints, exploit details that expose users, or other sensitive information.

If GitHub private vulnerability reporting is available in the repository's **Security** tab, use it.

If private reporting is not available, open only a minimal public issue saying that you found a security concern and need a private contact channel. Do not include the sensitive details in that issue.

This repository must remain free of real LIVE credentials, private production integrations and secrets.
